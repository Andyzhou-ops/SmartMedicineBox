This is a project based on the Raspberry Pi Linux system. It can provide voice interaction (with preset wake-up phrases) and face recognition. 
Of course, you can also run the program on Windows. The accompanying face recognition and speech models are already in the folder. 
You can use it as a base for further improvement; its speech module and face recognition module are both excellent. 
The best part is that it can be deployed on hardware. If it has helped you, give me a little star~
